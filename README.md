# Control de Cuentas Diarias

Aplicación web desarrollada en JavaScript para registrar ingresos y gastos diarios.

## Funcionalidades

* Alta de movimientos
* Registro de ingresos y gastos
* Categorías dinámicas desde JSON
* Cálculo automático de saldo
* Estadísticas por categoría
* Filtro por categoría
* Buscador de movimientos
* Persistencia de datos con LocalStorage
* Gráfico dinámico con Chart.js
* Alertas con SweetAlert2

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Fetch API
* JSON
* LocalStorage
* Chart.js
* SweetAlert2
* Git
* GitHub
